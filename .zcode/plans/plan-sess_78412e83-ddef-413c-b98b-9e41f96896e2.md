# 修复：点击通知后 PowerShell 窗口闪现

## 根因

协议处理器注册的命令是直接启动 `powershell.exe -WindowStyle Hidden`。PowerShell 是控制台程序：窗口先被创建，之后才应用 Hidden 参数 → 点击 toast 时先闪一个 PS 窗口，再隐藏，然后才轮到 mycode 聚焦。

## 修复方案：wscript 隐形启动器（标准做法）

`wscript.exe` 是 GUI 子系统程序，**从头到尾不创建任何控制台窗口**；由它以 `Run(..., 0, False)`（SW_HIDE + 异步）拉起 PowerShell，实现零闪现。

改动仍在 `attention.ts` 的 windowsToast PS 脚本内：

1. **生成 `mycode-focus.vbs`**（%TEMP%，懒生成，纯 ASCII 内容经 `ExpandEnvironmentStrings("%TEMP%\mycode-focus.ps1")` 定位 ps1，与用户名中文路径无关）：
   ```vbs
   Dim sh, ps
   Set sh = CreateObject("WScript.Shell")
   ps = sh.ExpandEnvironmentStrings("%TEMP%\mycode-focus.ps1")
   sh.Run "powershell.exe -NoProfile -ExecutionPolicy Bypass -File """ & ps & """", 0, False
   ```
2. **协议注册命令改为** `wscript.exe "C:\Users\...\mycode-focus.vbs"`（绝对路径，注册表本身是 Unicode，中文用户名安全）
3. **注册逻辑改为"命令值不符即重写"**（不能再用"存在即跳过"——你机器上已注册了旧的直接调 PS 的命令，需要自动迁移；顺带 %TEMP% 路径变化时也会自愈）
